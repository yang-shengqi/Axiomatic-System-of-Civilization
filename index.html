系统定位 System Positioning

杨晟琦文明公理系统 是一套自洽的、可检验的文明底层逻辑框架。 Yang Shengqi's Axiomatic System of Civilization is a self-consistent, testable foundational framework for civilization at the logical level.

它从公理定义出发，经诊断模型、度量工具、过程监测、药方设计、操作手册到验证工具，构成完整闭环。 It forms a complete closed loop, from axiomatic definitions through diagnostic models, measurement tools, process monitoring, prescription design, operational manuals, to validation instruments.

它不依附于任何国家、政权、资本或组织，不依赖任何外部条件。 It is not affiliated with any state, regime, capital, or organization, and depends on no external conditions.

它的唯一前提是：系统愿意被对照检验。 Its only premise: the system is willing to be examined against this benchmark.

核心特点 Core Features

1. 三段式结构：方向 → 诊断 → 处方，逻辑不可拆分，缺一则系统失效。 Three-stage structure: Direction → Diagnosis → Prescription. Indivisible logic; missing one breaks the system.
2. 可计算函数：文明指数将“文明”从修辞转化为可测量的数学公式。 Computable function: The Civilization Index transforms "civilization" from rhetoric into a measurable mathematical formula.
3. 三条元法则：基石否决权、体感优先律、最短木桶律，封堵一切数据粉饰与选择性执行。 Three meta-principles: Cornerstone Veto, Primacy of Lived Experience, Shortest Plank Rule — blocking all data manipulation and selective enforcement.
4. 九式诊断路径：从结构性不公到结构性死亡，完整揭示系统如何走向崩溃。 Nine-step diagnostic path: From structural injustice to structural death, fully revealing how a system collapses.
5. 双重锁定：法律铁索 + 三重剥离 + 物理隔绝，使制度具有反脆弱性。 Dual legal-physical lock: Legal Chains + Threefold Severance + Physical Isolation, rendering the institution anti-fragile.
6. 非归责性操作手册：七条方法论不追究个人责任，只提供可执行的系统翻转路径。 Non-attributional operations manual: Seven methodologies that do not blame individuals, only providing executable pathways to reverse the system.
7. 独立验证机制：用系统自身的工具检验系统自身，完成完整闭环验收。 Independent verification mechanism: Using the system's own tools to audit itself, completing a full closed-loop validation.
8. 无条件启动：不依赖“好领导”或“足够资源”，只依赖系统愿意被对照检验。 Unconditional activation: Does not depend on "good leadership" or "sufficient resources" — only on a willingness to be tested.

体系概述 System Overview

本体系是一套从公理定义到验收报告的完整思想架构，由十一篇核心文档构成，分为七个逻辑层，每一层都不可省略，缺一则系统失效。 This system is a complete intellectual architecture from axiomatic definition to acceptance report, composed of eleven core documents organized into seven logical layers. Each layer is indispensable; missing any one renders the entire system invalid.
